实验里研究什么？

本关使用理想序列。真实传感器的噪声与分辨率不会仅因增加采样次数就按这个规律消失。

这些符号是什么意思？
n 与 aₙ
n 是序号，aₙ 是第 n 个读数。
ε（epsilon）
允许误差，是一个正数。
N
保证生效的阈值；要求每个整数 n>N 都满足。

另看一个例子：bₙ=5+4/n，目标是 5。先算 |bₙ−5|=4/n，再把它与允许误差比较。回到本题时重新计算误差分子。

示例帮助理解方法；正式作答请使用本步骤的条件与参数。
怎样检查我的结果？

检查第一个受保证的整数 N+1；“<”与“≤”的边界不同。保证一次接近与保证后续全都接近是两件事。

还需要补一点基础？
函数：谁随谁变化？

T(t) 表示时间为 t 时的温度。t 是自变量，T 是读数；公式中的参数在本次计算中保持固定，除非题目说明它也在变化。

若 t 以分钟计，T(t)=20+30e^(−t/5)，则 T(0)=50。20 是环境温度，5 是以分钟计的时间尺度。

先找自变量、单位和固定参数。知道某一时刻的读数，不等于整个过程都保持这个读数。

单位：算出的是什么量？

相加的量需要相同单位；乘、除之后，单位也要一起计算。毫升每秒是流量，毫升是体积。

恒定流量 3 mL/s 持续 4 s，通过体积为 3×4=12 mL。60 mL/min=1 mL/s。

分钟与秒先统一。指数和三角函数的自变量须无量纲，例如 t/τ；三角求导使用弧度。

数值与正负号

先规定正方向。负速度表示沿负方向运动，不是“速度不存在”；速率是速度的大小。分数也是精确数值。

沿正向走 3 m，再反向走 2 m，位移是 1 m，路程是 5 m。1/4 与 0.25 表示相同的数。

输入框可填整数、小数或分数。题面若写 Aπ、Be 或根式结构，只填所问的系数，不用把整个式子输入。

导数：这一瞬间变化多快？

曲线的高度是读数，斜率是变化率。先用非零时间间隔算 Δx/Δt，再研究间隔趋近 0 时的极限；不能直接除以 0。

取 x(t)=t²，则从 t=3 到 t=3+h 的平均变化率是 6+h；h 趋近 0 时，x′(3)=6。位置求导是速度，速度再求导是加速度。

导数单位是纵轴单位除以横轴单位。左右得到不同极限时，不能报告一个共同的有限导数。

微分与有限变化

Δx 是实际的有限变化。微分关系 dy=f′(x)dx 给出线性变化模型，用它估计有限变化时写 Δy≈f′(x)Δx，并检查步长。

f(x)=x²，在 x=3 附近取 Δx=0.1，线性预测 Δf≈6×0.1=0.6；实际 Δf=0.61，误差来自 (Δx)²。

近似号不能随意改为等号。改变输入步长后，需要重新检查误差；小步长实验也不自动成为精确证明。
